# Polaris Sound Lab — sitio web

Estudio privado · Mérida, Yucatán, México · **https://drophlex.github.io**

Sitio estático (HTML/CSS/JS, sin dependencias) con **ÓRBITA mini**, un sintetizador generativo en Web Audio que suena desde la primera interacción y se apaga con un clic (o con `Esc`).

## Editar
- Textos, estilos y código: `src/index.html`, `src/style.css`, `src/app.js`
- Después de editar: `python3 build.py` → genera `index.html`
- Videos de YouTube destacados: lista `VIDEOS` al inicio de `src/app.js` (pega el ID de 11 caracteres)
- Software: lista `SOFT` en `src/app.js`

## Dominio propio (opcional)
Compra el dominio (Cloudflare / Porkbun ≈ US$10–12 al año para .com), crea un archivo `CNAME` con el dominio
y apunta los DNS a GitHub Pages (Settings → Pages → Custom domain).
